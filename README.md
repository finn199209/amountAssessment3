# 移动端贷款申请结果演示页

本项目是纯静态前端 Demo，仅用于界面演示和内部测试，不构成任何金融凭证。

## 本地运行

直接在浏览器中打开当前目录的 `index.html`：

```text
index.html
```

项目不依赖后端、数据库、接口、构建工具或 CDN，也可以由任意静态文件服务托管当前目录。

## 测试方式

1. 打开 `index.html`。
2. 填写授信金额、企业名称、统一社会信用代码、年化利率、申请日期、还款方式和还款周期。
3. 点击“生成结果页面”。
4. 校验失败时，检查字段下方红色错误提示和焦点定位。
5. 校验成功后跳转到 `result.html`，确认金额已从万元转换为元并保留两位小数。
6. 直接访问 `result.html`，确认页面显示“未获取到申请信息，请返回重新填写”。
7. 使用浏览器移动端模拟宽度 320px、375px、390px、414px、430px，确认无横向滚动。
