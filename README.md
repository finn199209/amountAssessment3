# 移动端贷款申请结果演示页

本项目是纯静态前端 Demo，仅用于界面演示和内部测试，不构成任何金融凭证。

## 本地运行

直接在浏览器中打开当前目录的 `password.html`：

```text
password.html
```

项目不依赖后端、数据库、接口、构建工具或 CDN，也可以由任意静态文件服务托管当前目录。

访问密码预设在 `js/password.js` 的 `presetPassword` 常量中，当前密码为 `HYH2026`。需要修改密码时，由页面维护者修改该常量后重新分发静态文件。

## 测试方式

1. 打开 `password.html`，输入预设访问密码。
2. 进入 `index.html` 后填写授信金额、企业名称、统一社会信用代码、年化利率、申请日期、还款方式和还款周期。
3. 点击“生成结果页面”。
4. 校验失败时，检查字段下方红色错误提示和焦点定位。
5. 校验成功后跳转到 `result.html`，确认金额已从万元转换为元并保留两位小数。
6. 关闭当前浏览器标签页后重新打开 `index.html`，确认需要重新输入密码。
7. 使用浏览器移动端模拟宽度 320px、375px、390px、414px、430px，确认无横向滚动。
